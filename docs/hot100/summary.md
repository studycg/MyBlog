# 哈希

**两数之和**：用哈希表存 `{数值: 下标}`，遍历时查找 `target - x`。//315

**字母异位词分组**：将字符串“排序”或“计数”后作为哈希表的 Key。//315

**最长连续序列**：数值存入 Set，只从“起点”（`x-1` 不存在时）开始枚举累加。//315

# 双指针

**移动零**：快慢指针，快指针找非 0 数，慢指针指向待覆盖位置。//315

**盛最多水的容器**：左右指针向中间靠拢，每次移动对应高度较短的那一侧。//315

**三数之和**：排序后固定一个数，余下两数用双指针左右夹逼。//315

**接雨水**：左右指针维护两端最大高度，每次结算较低那一侧的存水量。//315

# 滑动窗口

**无重复字符的最长子串**：快指针右移进窗，遇重复则慢指针右移缩窗，哈希表存每个字符最近出现位置。//315

**找到字符串中所有字母异位词**：维护定长窗口内的字符频率，与目标频率对比。//315

# 子串

**和为 K 的子数组**：利用**前缀和 + 哈希表**，统计 `prefixSum - k` 出现的次数。//315

**滑动窗口最大值**：使用**单调队列**（双端队列），保持队列内元素下标对应的数值递减。//315

**最小覆盖子串**：右边界覆盖所有目标字符后，左边界收缩至极限，更新全局最小。//315

# 普通数组

**最大子数组和**：动态规划（贪心），若当前和小于 0 则舍弃，重新开始累加。//315

**合并区间**：按起点排序，后一个区间的起点若小于前一个的终点则合并。//315

**轮转数组**：三次翻转（翻转全部，翻转前 $k$ 个，翻转剩余部分）。//315

**除自身以外数组的乘积**：分别计算前缀乘积和后缀乘积，两者相乘。//315

**缺失的第一个正数**：原地哈希，把数字 $x$ 放到下标 $x-1$ 的位置。//315

# 矩阵

**矩阵置零**：用第一行/第一列标记该行/列是否需要清零。

**螺旋矩阵**：维护上下左右四个边界，按层/顺时针收缩遍历。

**旋转图像**：先沿主对角线翻转，再左右翻转（等价于顺时针旋转 90°）。

**搜索二维矩阵 II**：从右上角（或左下角）开始搜索，类似二叉搜索树。

# 链表

**相交链表**：双指针 $A$ 和 $B$ 走完各自路径后再走对方的路，终会相遇。

**反转链表**：三指针（`prev`, `curr`, `next`）迭代改变指向。

**回文链表**：快慢指针找中点，反转后半部分，再与前半部分对比。

**环形链表**：快慢指针，若有环则快慢指针必相遇。

**环形链表 II**：相遇后，一指针回到起点，两指针同速前进，再次相遇点即为环入口。

**合并两个有序链表**：迭代对比头节点，依次连接较小值。

**两数相加**：模拟加法，逐位处理进位 `carry`。

**删除链表的倒数第 N 个结点**：快指针先走 $N$ 步，然后快慢指针同步走。

**两两交换链表中的节点**：递归或设置 Dummy 节点迭代处理断开重连。

**K 个一组翻转链表**：拆分为若干长为 $K$ 的子链表，分别调用反转函数。

**随机链表的复制**：在原节点后插克隆节点，处理 Random 指针后再拆分。

**排序链表**：归并排序，快慢指针找中点拆分，再合并。

**合并 K 个升序链表**：使用**最小堆**维护 K 个链表的当前最小值。

**LRU 缓存**：哈希表（快速查找）+ 双向链表（快速移动/删除最近使用的元素）。

# 二叉树

**二叉树的中序遍历**：递归（左-根-右）或栈模拟。

**二叉树的最大深度**：递归，$\max(\text{left}, \text{right}) + 1$。

**翻转二叉树**：递归交换每个节点的左右孩子。

**对称二叉树**：递归对比“左子树的左”与“右子树的右”是否相等。

**二叉树的直径**：递归求深度，过程中更新 `left + right` 的最大值。

**二叉树的层序遍历**：使用队列（BFS）逐层弹出。

**将有序数组转换为二叉搜索树**：取数组中点作为根，递归构建左右子树。

**验证二叉搜索树**：递归判断节点值是否在全局的 `(min, max)` 范围内。

**二叉搜索树中第 K 小的元素**：中序遍历（左-根-右）到第 $K$ 个元素即可。

**二叉树的右视图**：BFS 每层取最后一个，或 DFS 优先访问右子树。

**二叉树展开为链表**：先将左子树移到右边，再将原右子树接到当前右子树末端。

**从前序与中序遍历序列构造二叉树**：前序找根，中序划分左右边界。

**路径总和 III**：**前缀和 + 递归 DFS**，记录路径上的累加和。

**二叉树的最近公共祖先**：递归寻找目标节点，若左右子树都有返回则根为祖先。

**二叉树中的最大路径和**：递归求节点最大贡献值，更新 `left + right + root`。

# 图论

**岛屿数量**：遍历矩阵，遇到 '1' 时进行 DFS/BFS 并将连通区域置 '0'。

**腐烂的橘子**：多源 BFS，每一层代表时间 +1。

**课程表**：拓扑排序，判断图中是否有环（入度为 0 进队）。

**实现 Trie (前缀树)**：用节点数组/哈希存 26 个字母的子节点。

# 回溯

**全排列**：递归 + `used` 数组标记。

**子集**：递归处理每个元素“选”或“不选”的两个分支。

**电话号码的字母组合**：按位映射字母，递归进入下一层。

**组合总和**：递归搜索，由于可重复选，递归时索引不加 1。

**括号生成**：递归，限制条件为 `left < n` 且 `right < left`。

**单词搜索**：从矩阵各点开始 DFS，匹配字符串并标记访问状态。

**分割回文串**：在间隙切分，若是回文则递归切分剩余部分。

**N 皇后**：逐行放置，用集合记录列及两条对角线的冲突。

# 二分查找

**搜索插入位置**：标准二分，返回 `left`。

**搜索二维矩阵**：将二维坐标转化为一维 $index/n$ 和 $index\%n$ 后二分。

**在排序数组中查找元素的第一个和最后一个位置**：两次二分，分别找左边界和右边界。

**搜索旋转排序数组**：二分，判断哪一半是有序的，再根据范围缩小。

**寻找旋转排序数组中的最小值**：二分，通过与右端点 `mid < right` 对比判断在左还是右。

**寻找两个正序数组的中位数**：二分划分线，确保左侧元素数相等且满足交叉小于关系。

# 栈

**有效的括号**：遇到左括号入栈，遇到右括号弹栈对比。

**最小栈**：维护一个辅助栈存储当前最小元素。

**字符串解码**：使用两个栈分别存“重复次数”和“当前字符串”。

**每日温度**：**单调栈**，栈内存储下标，遇到更大温度时弹出并计算差值。

**柱状图中最大的矩形**：**单调栈**，找到每个柱子左右两侧第一个更短的。

# 堆

**数组中的第 K 个最大元素**：建立小顶堆（容量为 K）或快排分治（Quick Select）。

**前 K 个高频元素**：哈希统计频率，然后用小顶堆或桶排序。

**数据流的中位数**：大顶堆存左半部，小顶堆存右半部，保持平衡。
