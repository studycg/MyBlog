# 快速排序

```c++
void quickSort(vector<int>& nums, int left, int right) {
    if (left >= right) return;

    int i = left, j = right;
    int pivot = nums[left];  // 选取基准（也可以选中间）

    while (i < j) {
        // 从右往左找第一个 < pivot 的数
        while (i < j && nums[j] >= pivot) j--;
        // 从左往右找第一个 > pivot 的数
        while (i < j && nums[i] <= pivot) i++;
        if (i < j) swap(nums[i], nums[j]);
    }

    // 把 pivot 放到正确位置
    swap(nums[left], nums[i]);

    quickSort(nums, left, i - 1);
    quickSort(nums, i + 1, right);
}
```

i是左半区的最后一个位置 一定比pivot小

# 使用栈模拟队列

如果出栈为空，入栈的都放入出栈中。

```c++
class MyQueue {
private:
    stack<int> inStack;
    stack<int> outStack;

public:
    MyQueue() {}

    void push(int x) {
        inStack.push(x);
    }

    int pop() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
        int val = outStack.top();
        outStack.pop();
        return val;
    }

    int peek() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
        return outStack.top();
    }

    bool empty() {
        return inStack.empty() && outStack.empty();
    }
};
```

# DP

二维DP基本都有点暴力

**爬楼梯**：$f(n) = f(n-1) + f(n-2)$。//403

**杨辉三角**：$dp[i][j] = dp[i-1][j-1] + dp[i-1][j]$。//403

**打家劫舍**：$dp[i] = \max(dp[i-1], dp[i-2] + nums[i])$。//403

**完全平方数**：$dp[i] = \min(dp[i], dp[i - j*j] + 1)$。//403

- `dp[i]`：组成`i`所需最少完全平方数个数（完全背包）。

**零钱兑换**：$dp[i] = \min(dp[i], dp[i - \text{coin}] + 1)$。//403

- `dp[i]`：组成`i`所需的最小硬币数（完全背包）。

**单词拆分**：$dp[i]$ 表示前 $i$ 个字符能否拆分，遍历 $j < i$ 检查 `s[j:i]`。//403

- `dp[i]`：前 i 个字符（`s[0:i-1]`）是否可以被拆分（完全背包变体）。
